# Protalone

Personal launchpad: a curated catalog of popular websites, and a private list of the sites you commonly visit.

The product and implementation plan is in [docs/PLAN.md](docs/PLAN.md). The working copy with checklists is a private Notion page: [Protalone — Product and Implementation Plan](https://app.notion.com/p/3f42ea02e00081b085e8f5b06aa1c6cf).

Implementation has not started. Phase 0 is the display name, the Supabase and Vercel projects, and a seed of at least 100 sites.
